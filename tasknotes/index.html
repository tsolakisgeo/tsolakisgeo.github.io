TaskNotes – Personal Calendar

This is Georgios Tsolakis’s personal connection between the TaskNotes plugin in Obsidian and Google Calendar. It is used to view calendar events alongside personal tasks and, where enabled, synchronize tasks or event changes with Google Calendar.

The connection is intended solely for the owner’s personal use. This page documents that personal configuration; it is not the official TaskNotes project website or a public sign-up service.

Google Calendar access

The integration uses Google OAuth authorization. Calendar access is limited to the permissions granted during connection and is used for the calendar features enabled in TaskNotes.
