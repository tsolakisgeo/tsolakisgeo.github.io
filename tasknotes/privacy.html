Privacy policy

TaskNotes – Personal Calendar
Last updated: 10 September 2026

Purpose and owner

Georgios Tsolakis operates this personal Google Calendar connection through the TaskNotes plugin in Obsidian. It is intended for the owner’s use, not as a service offered to other users.

Data accessed and use

Depending on the permissions granted and features enabled, TaskNotes accesses calendar lists and event data, including event titles, dates, times, descriptions, locations, and other event fields returned by Google. It uses this information to display calendars in Obsidian and support enabled synchronization features. When authorized and enabled, it may create or update Google Calendar events from TaskNotes.

Storage and sharing

Calendar data is exchanged between TaskNotes running in Obsidian and Google’s services. TaskNotes stores connection credentials locally; current versions use Obsidian Secret Storage. Locally retained task or calendar information may also be included in the owner’s configured vault synchronization and backups.

The owner does not sell Google user data or use it for advertising, credit decisions, or training generalized artificial intelligence models. Google user data is used only for the personal calendar functionality described here. This integration’s use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

This website

These informational pages do not request Google login, receive OAuth tokens, or collect calendar data. They contain no analytics scripts or forms. GitHub Pages hosts the pages and may process normal request information under GitHub’s privacy statement.

Revoking access and deleting data

The owner can disconnect the account in TaskNotes and revoke the connection through Google Account connections. Revocation prevents further authorized access but does not automatically delete existing Google events or local records. Those records and any synchronized or backup copies can be removed separately using the relevant application or storage settings.

Contact and changes

Questions: tsolakisgeo@gmail.com. This policy should be updated if the integration’s purpose or handling of data changes.
